# دکتر عبدالرحیم حزینی | کانون حامیان بیماران سرطانی مهر گلستان

وب‌سایت رسمی پورتال تخصصی دکتر عبدالرحیم حزینی (فوق تخصص خون، انکولوژی و طب تسکینی) و کانون حامیان بیماران سرطانی مهر گلستان.

## 📄 صفحات وب‌سایت
- **صفحه اصلی (`index.html`)**: معرفی کانون، پیام‌ها، آمار خدمات و دسترسی سریع
- **درباره ما (`about.html`)**: تاریخچه کانون، معرفی اعضا و اهداف
- **خدمات و تجهیزات (`services.html`)**: مراقبت در منزل، امانت تجهیزات پزشکی و طب تسکینی
- **کمک‌های مردمی و نذورات (`donate.html`)**: درگاه‌ها و روش‌های حمایت و اهدای تجهیزات
- **گزارش‌ها و عملکرد (`reports.html`)**: گزارش‌های مالی و عملکرد سالیانه
- **مقالات و آموزش (`articles.html`)**: مقالات علمی طب تسکینی و انکولوژی
- **بروشورها و راهنماها (`brochures.html`)**: فایل‌های آموزشی و بروشورهای راهنما
- **گالری و رسانه (`media.html`)**: تصاویر، ویدیوها و فعالیت‌های میدانی
- **تماس با ما (`contact.html`)**: راه‌های ارتباطی، آدرس و فرم تماس

## 🚀 اجرا و پیش‌نمایش
این پروژه یک وب‌سایت استاتیک (HTML5 / CSS3 / JavaScript) است و نیاز به سرور یا پایگاه داده خاصی ندارد. کافی است فایل `index.html` را در هر مرورگری باز کنید یا از افزونه **Live Server** در VS Code استفاده نمایید.

## 🌐 انتشار روی GitHub Pages
برای مشاهده آنلاین این وب‌سایت از طریق GitHub:
1. به تب **Settings** در مخزن گیت‌هاب بروید.
2. از منوی سمت چپ بخش **Pages** را انتخاب کنید.
3. در بخش **Branch** شاخه `main` و مسیر `/ (root)` را ذخیره کنید.
